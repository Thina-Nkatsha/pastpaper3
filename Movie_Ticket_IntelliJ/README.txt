MOVIE TICKET JAVA PROGRAM

Open MovieTicketApplication.java in IntelliJ IDEA and run the main method.

The program asks for:
- Customer name
- Movie title
- Customer age
- Movie price

A 10% discount is applied when the customer is 65 years old or older.
Customers under 65 receive no discount.

The program then prints the movie ticket with:
- Customer name
- Movie title
- Movie price
- Discount
- Final cost due
